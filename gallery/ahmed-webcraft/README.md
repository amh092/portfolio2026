# Ahmed Webcraft — gallery package

Ready-to-use assets and bilingual project details for adding this portfolio to your project gallery.

## Add to your gallery

1. Use `images/ahmed-webcraft.webp` as the project card cover (16:10).
2. Use the English or Arabic text below, or import `project.json` into your gallery data. Its fields match this repository's `Project` type in `src/types/project.ts`.
3. In a gallery using the same public-folder convention, copy the cover to `public/images/projects/ahmed-webcraft.webp`. Otherwise update the JSON `image` path to your uploaded asset URL.
4. Add your preferred images from `screenshots/` to the project detail page.
5. Link the project to the live demo below.

This folder is a prepared listing package; adding its data to the destination gallery is a separate step.

## English listing

**Title:** Ahmed Webcraft

**Category:** Developer portfolio / Web development / Interactive 3D

**Short description:** A bilingual developer portfolio showcasing web projects, services, and interactive 3D work — with Arabic RTL layouts, dark and light themes, and responsive design.

**Full description:** Ahmed Webcraft brings project case studies, services, skills, and direct contact links together in a responsive English and Arabic portfolio. Each project presents its problem, solution, features, technology stack, and live demo. Visitors can switch languages, choose a dark or light theme, and explore three robot models through on-demand 3D viewers with rotation, zoom, reset, and loading controls. Built with Next.js, React, TypeScript, Tailwind CSS, next-intl, Three.js, React Three Fiber, and Motion.

**Highlights:** Arabic RTL support; saved theme preference; project case studies; interactive 3D viewers; responsive layouts; reduced-motion support; localized metadata and social images.
